# 任务书（原文存档）

> 本文件为客户原始任务书逐字存档，未作任何改动。达成度核账见 `reports/模块达成度_2026-11-02.md`，缺口核算见 `reports/采集缺口_2026-11-02.md`。

## 一、模块与目标

任务书需要，尽量需要按照这些维度：

| 级别 | 模块 | 内容 | 目标（有效案例） |
|---|---|---|---|
| P0 | A | 爱回收二奢回收的负面案例 | ≥60 条 |
| P0 | A | 转转二奢回收的负面案例 | ≥60 条 |
| P0 | B | 闲鱼现有回收（含原"省心卖"）和验货宝的二奢负面案例 | ≥60 条 |
| P1 | C | 三家平台的公开回收规则和用户协议对标 | 每家 1 份 |
| P1 | D | 闲鱼二奢卖家和买家观察（见第七节） | 独立成文 |
| P1 | E | 第二回合、SNAKE 的公开负面自查 | 全量 |
| P2 | F | 红布林、心上等其他二奢回收平台的对照案例 | ≥30 条 |

目标数不是硬指标。如果二奢案例确实稀少，如实报告实际数量和检索过程，不得放宽标准凑数。"公开二奢案例很少"本身就是一个结论。P0 未达标时，不要把时间挪去做 P2。

## 二、判定标准

- **品类**：箱包、腕表、首饰（不含纯金价回收）、奢品和潮流鞋服、配饰算二奢。手机、数码、家电、普通书籍衣物不算。
- **业务**：只要 C2B 回收（用户把货卖给平台或服务商）。C2C 交易纠纷只有在涉及验货宝时才收。
- **时间**：2024-01-01 至今，优先近 12 个月。更早的只收媒体或监管级别的重大事件，并标注时间。

## 三、必须注意的三点

1. **3C 噪音极大。** 10-30 试搜显示，"爱回收 压价"一类结果几乎都是手机。必须组合品类词检索，并逐条判断品类。
2. **要记录回收方式和业务线。**
   - 爱回收的包表首饰由值耀承接，鞋服配饰由第二回合承接，两条线不能混。
   - 爱回收鞋服配饰的邮寄回收已于 2026-07-09 下线，现在只有门店和上门。
   - 每条案例都要记录品类和回收方式（邮寄、门店、上门、不明），否则无法判断是否适用于闲鱼。
3. **涉及我方的案例要单独处理。** 爱回收鞋服配饰的案例可能是第二回合实际承接的订单。这类案例照常入库并打 我方相关=疑似，但不得联系任何人，也不得与渠道方沟通。

## 四、不在范围内

- 不查库，不使用任何内部数据，也不向内部同事索要客诉数据。
- 不涉及鉴定、质检服务商之间的行业传闻或爆料，也不涉及抖音相关内容。碰到不收集、不摘录。
- 含实名刑事指控的内容不摘录正文，只记录链接并报告老万。
